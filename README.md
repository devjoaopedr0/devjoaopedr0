## 🚀 Projetos em Destaque

### 🌱 EcoTech / IrrigaAI

Sistema inteligente de irrigação que combina **IoT, sensores, automação e Inteligência Artificial** para otimizar o uso de água.

O projeto utiliza dispositivos como **ESP32, sensores de umidade e relés**, permitindo monitoramento das condições do solo e acionamento inteligente da irrigação.

**Tecnologias e conceitos:**

`ESP32` `IoT` `Sensores` `Automação` `APIs` `IA` `React`

🏆 Projeto premiado em **1º lugar no Ceará Científico**.

---

### 📚 Lumina

Plataforma **EdTech/SaaS** voltada para estudantes e instituições de ensino, com foco na preparação para vestibulares e ENEM.

A plataforma integra recursos de organização de estudos, questões, correção de avaliações e Inteligência Artificial através da **LuminIA**.

**Stack:**

`React` `TypeScript` `Vite` `Node.js` `PostgreSQL` `Prisma` `Docker` `IA`

---

### ☕ Task Manager

Aplicação desenvolvida em **Java** para gerenciamento de tarefas, explorando arquitetura de software, persistência de dados e desenvolvimento de aplicações.

**Stack:**

`Java` `JavaFX` `Maven` `DAO` `SQL` `JUnit`
